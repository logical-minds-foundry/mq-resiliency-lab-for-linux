Native HA arm — log-replicated HA in a site, async CRR across the WAN

3 instances, log-based (raft) synchronous replication, automatic failover, RPO 0 in-site. No shared storage and no VIP — clients use a 3-instance CONNAME list + auto-reconnect. Two OS arms: nha-ubuntu and nha-rhel.

No VIP, no shared disk. Native HA replicates the recovery log across 3 instances over the heartbeat net; one instance is the raft leader (Active). There is no floating IP — clients reach the QM by a comma-separated list of all three instance addresses and reconnect to whichever is Active. Cross-site resilience is a separate, asynchronous CRR relationship with a manual cutover — never a stretched sync group.

The building block — one queue manager, 3-instance HA + async CRR

QM NHAUAPP / NHARAPP — automatic HA inside DC-A, manual async CRR to DC-B.
