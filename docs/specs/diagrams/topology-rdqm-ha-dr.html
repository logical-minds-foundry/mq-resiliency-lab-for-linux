RDQM done right — building block + active/active vision

HA groups are 3-node, synchronous, single-site. Cross-site is always asynchronous DR with manual cutover. No node ever stretches across the WAN.

Why no stretched groups? An RDQM HA group replicates synchronously and is a single quorum domain. Putting any member in the other data center (the "2+1" idea, or "one node from each") ties every commit to inter-site latency and makes a DC-to-DC network partition collapse the cluster instead of giving clean DR. Cross-site resilience is a separate, asynchronous DR relationship — never a stretched sync group.
